# Security Policy

## Supported versions

Security fixes are applied to the latest release. Users should keep the marketplace on its default branch so updates are received automatically.

## Report a vulnerability

Do not open a public issue for suspected vulnerabilities, exposed credentials, or private data. Use GitHub's private vulnerability reporting for this repository. Include reproduction steps, affected versions, and impact, but never include real customer data or active secrets.

If a secret or private record may have been published, revoke or rotate it immediately before investigating repository cleanup.

## Security guarantees

Agent Creator uses layered preventive controls, but no scanner can guarantee detection of every sensitive value. Machine access, GitHub access, and deliberate bypasses remain outside the plugin's control.
